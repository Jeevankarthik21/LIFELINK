LIFELINK — FIVE SEPARATE HTML PAGES
===================================

FILES
- index.html             Overview / home page
- find-donors.html       Donor search page
- register-donor.html    Donor registration page
- emergency-request.html Emergency request form
- dashboard.html         Request management page
- styles.css             Shared design for all pages
- common.js              Shared local demo data utilities
- find-donors.js         Donor search behavior
- register-donor.js      Registration behavior
- emergency-request.js   Request submission behavior
- dashboard.js           Dashboard and status updates

RUN
1. Extract LifeLink_5_Pages.zip.
2. Open VS Code > File > Open Folder > choose LifeLink_5_Pages.
3. Open index.html and use Live Server (right-click > Open with Live Server).
4. Use the left sidebar to navigate between five separate HTML pages.

IMPORTANT
This is a local frontend prototype using browser localStorage. The pages share data when
opened on the same browser origin (use Live Server for consistent behavior). It does not
include a cloud database, authentication, real notifications, or hospital verification.
Use fictional data only. For real emergencies, contact the hospital and authorized blood
bank directly. Medical professionals must verify donor eligibility and compatibility.
